# wp_fibra

Papéis de parede da Fibrasol, baixados automaticamente pelo myWallpapers (origem "Fibrasol (GitHub)").

- `manifesto.json` lista cada imagem com nome, tamanho e hash (SHA-256). O programa só baixa o que é novo ou mudou e remove o que saiu da lista.
- Para trocar as imagens: adicione, troque ou remova os arquivos desta pasta e regenere o manifesto (mesmos arquivos, mesmo formato).
- Os mesmos arquivos também estão na Release `wp_fibra` deste repositório, que é o endereço que o programa usa hoje.
