# wp_barreto

Papéis de parede da Barreto Material de Construção (1920x1080), baixados automaticamente pelo myWallpapers (origem "Barreto (GitHub)").

- `manifesto.json` lista cada imagem com nome, tamanho e hash (SHA-256). O programa só baixa o que é novo ou mudou e remove o que saiu da lista.
- Para trocar as imagens: altere os arquivos desta pasta e da Release `wp_barreto` e regenere o manifesto.
